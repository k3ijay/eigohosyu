# iTL 英語補習 課題回答アシスタント

中央大学国際情報学部（iTL）の英語補習の課題提出時、manaba の「HTMLを編集」機能で提出する際のフォーマット整形を補助する、個人開発の非公式 Web アプリケーションです。

なお、本リポジトリに公開しているソースコード・画像等の転載、改変、再配布を無断で行わないでください。

## 今すぐ使うには

👉 [**課題回答アシスタントはこちら**](https://k3ijay.github.io/eigohosyu)

ブラウザ上でそのまま動作するので、インストールやログインは不要で今すぐ使えます！

---

## 使い方

1. [https://k3ijay.github.io/eigohosyu](https://k3ijay.github.io/eigohosyu) を開きます。
2. **時期と週の選択** で「後期」を選択し、**Week** のドロップダウンから `4` 〜 `13` を選択します。
3. 表示された入力欄に文章を入力します（奇数週の場合は併用した AI と 9 項目の評価も設定します）。
4. **完成品** の「コードプレビュー」および「表示プレビュー」で内容を確認し、**コピー** ボタンを押します。
5. manaba の該当する週のプロジェクトページで「コメントを書く」→ 右側の「HTMLを編集」を開き、コピーしたコードをペーストします。
6. 提出前に必ず manaba 上の「プレビュー」ボタンを押し、表示崩れがないか確認してから提出してください。

## 主な機能

- **時期・Week によるフォーム自動切り替え**
  - **前期・後期** と **Week（4〜13）** をドロップダウンで選択できます。
  - 後期の Week 番号に応じて **偶数週・奇数週** を自動判定し、入力欄と出力フォーマットを切り替えます。
  - ※ 前期向けの機能は将来的に実装する予定です。
- **後期 偶数週**
  - 入力した文章を改行ごとに `<p>...</p>` 段落タグへ自動変換します（空行は除外され、`&` `<` `>` などの HTML 特殊文字は自動エスケープされ、HTML タグとして解釈されません）。
- **後期 奇数週**
  - 以下の 3 部構成の HTML を自動生成します。
    1. `１．`：本文の段落整形
    2. `２．【添削】`：本文の段落整形、および、併用した AI ツールの表記設定
       - **DeepL Write**〔デフォルト〕
       - **その他のAI**〔モデル名を自由入力〕
       - **AIの併用なし**
    3. `３．【評価】`：9 項目の自己評価をスライダー（`低 = 0.0` / `中 = 0.5` / `高 = 1.0`、初期値 `中`）で選択し、指定通りの表を自動生成
- **リアルタイムプレビュー**
  - 入力内容に応じて **コードプレビュー** と **表示プレビュー** をリアルタイムで更新します。
- **コピー・入力クリア機能**
  - **コピー** ボタンを一度押すだけで生成されたコードをクリップボードにコピーします。その際に、manaba への提出手順もポップアップで案内されます。
  - **入力をクリア** ボタンで現在表示中の週の入力内容をリセットできます。

## ローカルでの動作確認

ビルドツールや外部パッケージは不要な静的 Web サイト（HTML / CSS / Vanilla JavaScript）です。

```bash
git clone https://github.com/k3ijay/eigohosyu.git
cd eigohosyu
```

`index.html` を直接ブラウザで開くか、任意のローカルサーバーで配信して確認できます。

```bash
# Python 3 を使用する場合の例
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## ファイル構成

| ファイル / ディレクトリ | 役割 |
| --- | --- |
| `index.html` | アプリケーションの画面構造・フォーム・モーダル・OGP / ファビコン設定 |
| `style.css` | 全体のスタイル定義（CSS 変数によるテーマ管理・レスポンシブ対応） |
| `app.js` | 週判定・入力サニタイズ・HTML 生成ロジック・UI イベント制御 |
| `manifest.webmanifest` | PWA 用 Web アプリマニフェスト |
| `favicon.ico` | デスクトップブラウザ向けマルチサイズファビコン（16×16 / 32×32 / 48×48） |
| `icons/` | 各 OS・ブラウザ・PWA 用の PNG アイコン一式（`apple-touch-icon` 等） |
| `assets/ogp.png` | SNS 共有用 OGP 画像（1200×630） |

## カスタマイズ

- **課題設定・評価項目の変更**：`app.js` 先頭の `CONFIG` オブジェクト内で、`minWeek` / `maxWeek`（週の範囲）、`defaultAiModel`、評価スケール（`scoreOptions` / `scoreLabels`）、見出し、評価項目リストを変更できます。
- **配色の変更**：`style.css` 先頭の `:root` にある CSS 変数からカラーやフォントを調整できます。
